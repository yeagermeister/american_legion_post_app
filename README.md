# American Legion Post App

**Purpose:**  
A React-based web application designed to serve as the digital hub for an American Legion Post.

**Why this exists:**  
To modernize the Post's communication and community engagement. This app provides members with easy access to event schedules, news, and resources, replacing outdated paper-based or disjointed communication methods with a centralized, accessible web platform.

## Features (Planned/Implemented)
- **Home Page:** Overview of the Post and upcoming highlights.
- **Events Calendar:** Schedule of meetings, fundraisers, and community events.
- **Membership Info:** Resources for current and prospective members.
- **Contact:** Easy ways to get in touch with Post leadership.

## Project Structure

- `client/`: React frontend application.
- `server/`: Backend Node.js/Express server (for API and data handling).

## Setup & Running

### Prerequisites
- Node.js (v16 or higher)
- npm (Node Package Manager)

### Client (Frontend)

1.  Navigate to the client directory:
    ```bash
    cd client
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm start
    ```
    The app should open in your browser at `http://localhost:3000`.

### Server (Backend)

1.  Navigate to the server directory:
    ```bash
    cd server
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the backend server:
    ```bash
    npm start
    ```
    (Ensure you configure any necessary environment variables in a `.env` file first).
